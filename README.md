# NEXA AI Workspace — GitHub Pages flat-file edition

All files belong **directly in the repository root**, alongside `index.html`. No `assets` folder is required.

Upload or replace: `index.html`, `chat.html`, `agents.html`, `activity.html`, `settings.html`, `style.css`, `app.js`, `nexa-background.png`, `nexa-original-logo.jpg`.

For GitHub Pages choose Settings → Pages → Deploy from a branch → `main` / `(root)`. Wait for deployment then refresh the published site (try private tab to bypass cache).

This is an interactive static demo; AI replies and agent state are simulations stored in the browser, not a real AI or blockchain service. Official X: https://x.com/NexaDotTech.
